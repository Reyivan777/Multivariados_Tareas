2. Trend and seasonality

Time series

plot(ventas_ts,
     type = "o",
     xlab = "Year",
     ylab = "Sales (thousands)",
     main = "Quarterly television sales")

La serie no es stationary, ya que presenta una trend general creciente y un seasonal pattern trimestral repetitivo. En particular, el segundo trimestre suele presentar las ventas más bajas y el cuarto las más altas.

Autocorrelation (ACF)

acf(as.numeric(ventas_ts),
    lag.max = 12,
    xlab = "Lag (quarters)",
    main = "Autocorrelation of sales")

La ACF muestra un valor importante en lag 4, consistente con quarterly seasonality: observaciones del mismo trimestre en años consecutivos tienden a comportarse de manera semejante.

Additive and multiplicative models

Se prueban las dos formas de decomposition para comparar cuál representa mejor la serie.

descomp_add <- decompose(ventas_ts, type = "additive")
descomp_mult <- decompose(ventas_ts, type = "multiplicative")

plot(descomp_add)

plot(descomp_mult)

Ambas decompositions representan el seasonal pattern. La elección final entre una estructura additive o multiplicative se realiza comparando los forecast errors de los modelos ajustados.

Al eliminar el seasonal effect, en ambas deseasonalized series se observa con mayor claridad la creciente trend de las ventas.

4. Linear trend model

Se ajustan linear models sobre las deseasonalized sales. El multiplicative model se analiza con mayor detalle y después se compara con los demás mediante sus forecast errors.

modelo_lineal_mult <- lm(as.numeric(ventas_des_mult) ~ tiempo)

El coefficient de time es significant (\(p=4.25\times10^{-9}\)), por lo que existe evidencia de una increasing trend. El model también es globally significant (\(p=4.25\times10^{-9}\)) y explica aproximadamente 92.1% de la variability de las deseasonalized sales (\(R^2=0.9208\)).

Los residuals no muestran un patrón fuerte de curvature o un cambio claro de variability. La observation 2 destaca respecto a las demás y conviene tenerla presente como una potentially influential observation. La Shapiro-Wilk test obtiene \(p=0.7307\), por lo que no se rechaza normality. Además, la residual ACF no presenta lags claramente significant, por lo que no se observa evidencia fuerte de remaining temporal dependence.

\[\hat{y}=4.7903+0.2533t-0.00623t^2\]

Tanto el linear term (\(p=3.56\times10^{-5}\)) como el quadratic term (\(p=0.0204\)) son significant. El model es globally significant y alcanza un \(R^2=0.9484\). El negative coefficient de \(t^2\) indica que las ventas siguen aumentando, pero el growth rate se va reduciendo con el tiempo.

6. MSE and MAPE

Se comparan tres models: additive linear, multiplicative linear y multiplicative quadratic.

pred_add_lin <- fitted(modelo_lineal_add) + estacional_add
pred_mult_lin <- fitted(modelo_lineal_mult) * estacional_mult
pred_mult_cuad <- fitted(modelo_cuad_mult) * estacional_mult

metricas <- function(real, pred) {
  c(
    MSE = mean((real - pred)^2, na.rm = TRUE),
    MAPE = mean(abs((real - pred) / real), na.rm = TRUE) * 100
  )
}

comparacion <- rbind(
  "Additive linear" = metricas(ventas, pred_add_lin),
  "Multiplicative linear" = metricas(ventas, pred_mult_lin),
  "Multiplicative quadratic" = metricas(ventas, pred_mult_cuad)
)

round(comparacion, 4)
##                             MSE   MAPE
## Additive linear          0.0329 2.4921
## Multiplicative linear    0.0330 2.4395
## Multiplicative quadratic 0.0219 1.9493

El multiplicative quadratic model presenta los menores forecast errors, con un Mean Squared Error (MSE) de 0.0219 y un Mean Absolute Percentage Error (MAPE) de 1.9493%. Por lo tanto, es el mejor de los tres models evaluados. Los dos linear models presentan resultados muy similares entre sí, pero ambos tienen mayores errors.

mejor_MSE <- rownames(comparacion)[which.min(comparacion[, "MSE"])]
mejor_MAPE <- rownames(comparacion)[which.min(comparacion[, "MAPE"])]

cat("Lowest MSE:", mejor_MSE, "\n")
## Lowest MSE: Multiplicative quadratic
cat("Lowest MAPE:", mejor_MAPE, "\n")
## Lowest MAPE: Multiplicative quadratic

Conclusion

La sales time series no es stationary porque presenta una increasing trend y quarterly seasonality. Después de obtener las deseasonalized series se ajustaron tres models. El multiplicative quadratic model fue el mejor, con MSE = 0.0219 y MAPE = 1.9493%, y sus terms resultaron statistically significant. Por ello se utiliza para forecast Year 5, manteniendo el seasonal pattern de menores ventas en Quarter 2 y mayores ventas en Quarter 4.
